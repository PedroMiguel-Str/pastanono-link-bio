# Pasta Nono — página de links

Página oficial de links do Bistrô Pasta Nono, publicada em
`https://pastanono.digitalwow.com.br`.

## Produção

- Hospedagem: VPS da Wow Digital via Coolify.
- Tipo: site estático.
- Fonte publicada: `index.html`, `fotos/index.html` (tela "Fotos dos eventos") e `assets/`.
- Novo evento de fotos: gerar `assets/eventos/<slug-data>/foto-N.webp` (até 1400px) e
  `mini-N.webp` (480x480), copiar o bloco `<article class="event">` em `fotos/index.html`
  (mais recente primeiro) e usar pasta do Drive compartilhada como "qualquer pessoa com o link".
- Alterações devem ser validadas visualmente em mobile antes do deploy.
